# Changelog for [Fish N' Ships](https://github.com/hybridlabs/fish-n-ships)

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.2] 2026-11-24

- Now available for Minecraft 26.2.
- Dinghies can now be crafted from every wood type. Before this release, only driftwood dinghies had crafting recipes.
- Vehicle recipes are now grouped together in the recipe book.

### Developer notes

- Dinghy recipes are generated by the recipe provider for every wood type. Before this change, only the driftwood recipes were emitted.
- Vehicle recipes now share a recipe-book group.

## [1.0.0] 2025-08-22

Initial public release.
